# Contributing evidence and corrections

[Project home](README.md) · [Claim register](docs/CLAIM_REGISTER.md)

Please identify the claim ID, exact wording being corrected, an independently retrievable source, a specific locator, and the scope of what the source supports. Distinguish the source’s own statement from your inference.

Preserve the specimen and user clarification. Do not infer endorsement from submission, authenticate a model from prose style, or replace unresolved claims with certainty. A source that repeats an accusation is not necessarily independent corroboration.

Keep new allegations about real people separate from established findings. Record contrary evidence and failed source checks. Do not publish private identifiers or unrelated conversation history.

Changes to analysis belong in the Markdown and JSON inputs. Run the builder and verifier, and describe material judgment changes in the changelog. An original generation export should be introduced as a separately identified source with a documented acquisition method; avoid quietly replacing the frozen v1 text.

No complete animal-operation registry is bundled. Contributions should not invent new Zoo animal definitions to manufacture a passing result.
